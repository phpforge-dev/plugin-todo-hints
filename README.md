# TODO Hints

Marca TODOs e FIXMEs e mostra a contagem no editor. Um arquivo `.todo-owners` na raiz do projeto permite sugerir responsáveis ao digitar `TODO(`.

No PHP IDE 0.2.9 ou superior, procure **TODO Hints** no Marketplace ou instale pela URL `https://github.com/phpforge-dev/plugin-todo-hints`. Também é possível instalar esta pasta ou um ZIP.

Autorize a leitura do projeto para usar `.todo-owners`. Sem essa permissão, as marcações e a contagem continuam funcionando.
